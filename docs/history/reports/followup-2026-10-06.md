## Recovery, review and deployment boundaries

prepared/graph_applied/complete journal states, replays scoped graph reconciliation
on recovery, then atomically publishes the file. The database and filesystem are
separate commit boundaries. Fault injection covers database failure and export
replacement failure. Concurrent publishers are not supported by this local tool.

case is flushed to disk; resume requires identical code, data, configuration and
ordered IDs. Completed summary files cannot be overwritten. The cached repair's

was pulled or built, no remote Actions job was run and no Phoenix export was

skip unavailable local steps.
